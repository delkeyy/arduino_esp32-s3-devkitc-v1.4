## 项目一：[esp32_01](./esp32_01/) — NeoPixel RGB LED

> 2026-07-16

循环显示红、绿、蓝、白、灭五种状态。

| 开发板引脚 | 外接设备 |
|-----------|---------|
| GPIO 48 | WS2812 NeoPixel RGB LED（1颗） |

- **开发板**：ESP32-S3-DevKitC v1.4
- **Arduino 开发板配置**：`ESP32S3 Dev Module`
- **依赖库**：Adafruit_NeoPixel
